Embedded Systems — STM32F0 Dev Board

A hands-on embedded systems project where I assembled a STM32F0 development board and programmed it in C to control LEDs, buttons and an LCD display.

What was the project?

This project was my introduction to embedded systems and gave me practical experience working with a microcontroller at hardware level. I assembled a UCT STM32F0 development board by hand before developing and testing programs on the board.

The project involved learning how digital logic translates into software, as well as how a microcontroller can respond to inputs and control different hardware components.

What I worked on

I programmed the STM32F0 in Embedded C to create a range of LED patterns and behaviours. These included a defined LED sequence, an 8-step scrolling pattern and an 8-bit binary counter that wrapped back to zero.

I also worked with button inputs and learned why switch debouncing is necessary when reading physical inputs. Another part of the project involved configuring the LCD and displaying text clearly on the screen.

Engineering decisions

Working directly with the microcontroller required careful consideration of how hardware inputs and outputs were represented in software. I had to structure the program around different states, flags and timing behaviour while ensuring that the physical hardware responded as intended.

Hand-assembling the development board also meant checking connections and solder joints carefully before testing the software. This helped me understand the relationship between the physical circuit and the code controlling it.

Skills demonstrated

Embedded C STM32F0 Microcontrollers GPIO Interrupts LCD Programming Hand Soldering Debugging

What I took from the project

This project strengthened my understanding of how software and hardware work together. It gave me practical experience programming in C for a physical system rather than simply writing code that runs on a computer.

Seeing an LED pattern or LCD message appear as a direct result of my code made the connection between programming, electronics and real-world systems much more tangible.
